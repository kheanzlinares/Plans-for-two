# Plans for Two

A single-page plan book and calendar for a couple: add as many plans as you like, each with its own icon and character (beach, mountains, city escape, adventure, foodie, movie & anime, gaming, dog day, mystery and more), see them on a month calendar, and hover a day to preview the details.

## Running it

- **Shared version (recommended):** the live copy is published as a Claude artifact with built-in shared storage. Share it with your partner as a *Contributor* so you both can add and edit plans.
- **This repo:** open `index.html` in a browser (or turn on GitHub Pages). Outside Claude, plans are saved in that browser only (`localStorage`), so two phones won't see each other's plans unless you add a backend.

No build step, no dependencies. Fonts load from Google Fonts.
